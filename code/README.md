# Mouse-GEM code

The model is generated by `code/animalGEM/generateAnimalGEM.py` in the
[Human-GEM](https://github.com/SysBioChalmers/Human-GEM) repository, which replaces the former
`masterScriptMouseGEM.m`. It reads the species-specific inputs from `data/` in this repository
and writes `model/`:

```
git clone https://github.com/SysBioChalmers/Human-GEM.git
git -C Human-GEM worktree add ../Human-GEM-release v2.1.0
python Human-GEM/code/animalGEM/generateAnimalGEM.py Mouse --repo Mouse-GEM --human-repo Human-GEM-release --solver gurobi
```

The model version follows Human-GEM's major.minor (this model is 2.1.z for Human-GEM 2.1); the patch
number is this model's own. `--version` sets it (also written to `version.txt`); `--date` fixes the model date.
